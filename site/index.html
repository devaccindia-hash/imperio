How it works

Three steps. No settings.

Both computers run the same file. Whoever needs help shares; whoever helps connects.

  1. Open Imperio on both PCs

    Double-click Imperio.exe. Sharing is ready the moment the window appears — the ID, the address and a one-time six-digit code are shown in big letters.

  2. Type the other PC’s address

    On the computer you are sitting at, enter the address and code you were told, then press Connect. The other person can be asked to click Yes first.

  3. Work as if you were there

    Their screen opens in its own window. Mouse, keyboard, clipboard text and sound just work. F11 for full screen; close the window to end.

Security

Built around trust, not tricks.

Remote control is a serious permission. Here is exactly what protects a session, in plain words, with the names of the real building blocks so you can check them.

  1. A one-time code only the two of you know

    The six-digit code is never sent. Both sides prove they know it with SPAKE2, a password-authenticated key exchange: someone listening learns nothing, and someone guessing gets one try per attempt before the host slows down and issues a new code.

  2. End-to-end encryption, every packet

    Screen, sound, keystrokes and clipboard are sealed with ChaCha20-Poly1305 using fresh keys for each session and each direction. Nothing in between can read or alter them.

  3. The same computer as last time

    Each computer has its own Ed25519 identity. Your Imperio remembers it on first contact; if a different machine answers later, the connection is refused instead of quietly going ahead.

  4. A person says Yes

    Turn on “Ask me before someone connects” and nothing is shown or controlled until the person at the computer approves. For unattended access you can add a second factor from an authenticator app (TOTP).

  5. Updates you can verify

    The update manifest is signed with the project’s Ed25519 release key and the download is checked against its SHA-256 before it is installed. A tampered file is rejected.

  6. Open-source client

    The program you run is published under MIT / Apache-2.0. You do not have to take any of the above on faith — read the source.

Questions

Things people ask.

Do both computers need Imperio?

Yes. It is the same file for both roles: the computer being controlled and the one you sit at.

Does it work over the internet?

Yes, whenever the other computer’s address is reachable: on the same network, or with both PCs on your Tailscale network (free). Direct internet connections through our own relay are coming next.

Windows SmartScreen shows a warning. Normal?

For a new, not-yet-signed program, yes. Click “More info” → “Run anyway”. Code signing is on the roadmap and will make the warning disappear. Until then you can compare the file’s SHA-256 with the one published at the bottom of this page.

Is it safe to leave running?

Nobody can connect without the current one-time code, and a few wrong guesses replace it. You can pause sharing with one switch, require a Yes / No on every connection, or quit from the tray icon.

Where do recordings go?

Videos ▸ Imperio, as MP4 files named by date and time. Turn recording on per session from the session menu, or always, in Sharing settings.

How do updates work?

Imperio checks for a new version when it starts and shows a banner (and a tray notification if it is running in the background). Click “Download and install”: it verifies the signature and checksum, then restarts itself.

What does the developer see?

Nothing about your sessions. The only network request the app makes on its own is to read a small version file to offer updates. This website uses no cookies, no analytics and no third-party scripts or fonts.

How do I get and use a Pro key?

Email admin@developerinayat.com. You receive a key starting with IMP-; paste it under Sharing settings → Plan. It is verified on your computer, with no licence server.
