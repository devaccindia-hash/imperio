How it works

Three steps. No settings.

Both computers run the same file. Whoever needs help shares; whoever helps connects.

1

Open Imperio on both PCs

Double-click Imperio.exe. Sharing is ready the moment the window appears — the ID, address and a one-time code are shown in big letters.

2

Type the other PC’s address

On the computer you are sitting at, enter the address (and code) you were told, then press Connect. The other person can be asked to click Yes first.

3

Work as if you were there

Their screen opens in its own window. Mouse, keyboard, clipboard and sound just work. F11 for full screen; close the window to end.

Why Imperio

Built around trust, not tricks.

No surprise lockouts, no account harvesting, no mystery servers in the middle. Just the connection you asked for.

Encrypted end to end

Every session gets a fresh key agreed only between the two computers. Each machine’s identity is pinned, so a swapped machine is noticed and refused.

Fast enough to forget it’s remote

Hardware video encoding on both ends, 60 fps, a handful of milliseconds on a local network, adaptive to slower links.

You decide who gets in

Pause sharing with one switch. Ask for a Yes/No before anyone connects. Or allow only your own Tailscale devices.

Record a session

Save any session as an MP4 for support notes or training — on demand, or always.

Honest billing

Free is free, including the occasional work task. No “commercial use detected” lockouts. Pro is a key you paste once.

Questions

Things people ask.

Do both computers need Imperio?

Yes. It is the same file for both roles: the computer being controlled and the one you sit at.

Does it work over the internet?

Yes, whenever the host’s address is reachable: same network, or both PCs on your Tailscale network (free). Direct internet connections through our relay are coming next.

Windows SmartScreen shows a warning. Normal?

For a new, not-yet-signed program, yes. Click “More info” → “Run anyway”. Code signing is on the roadmap and will make the warning disappear.

Where do recordings go?

Videos ▸ Imperio, as MP4 files named by date and time. Turn recording on per session from the session menu, or always, in Sharing settings.

How do updates work?

Imperio checks for a new version when it starts and shows a banner (and a tray notification if it is running in the background). Click “Download and install”: it verifies the download and restarts itself.

What does the developer see?

Nothing about your sessions. The only network request the app makes on its own is to read a small version file to offer updates.
